Кастомный движок для скриптов (мини-режимы на 1.20.1)

🔥 Custom Script Engine — это моя главная разработка. Платформа, позволяющая создавать, управлять и запускать мини-режимы (PvP арены, квесты, сражения с боссами, паркур) на сервере Minecraft 1.20.1 через простые скрипты и конфигурации, без перекомпиляции ядра.

Java 17+ Script API (JS, Groovy поддержка) Динамическая загрузка Мини-режимы на лету

Скриптовая архитектура

Режимы описываются на скриптовых языках — JS/Lua + специальный DSL. Управление жизненным циклом, ивентами, условиями победы — всё через простой API.

Молниеносное развертывание

Горячая перезагрузка скриптов, создание новых мини-игр без остановки сервера. Адаптация под любую механику: от "King of the Hill" до "One in the Chamber".

Оптимизация и совместимость

Нативная поддержка Paper 1.20.1, асинхронные обработчики событий, защита от лагов. Движок написан на чистой Java с упором на производительность.

Гибкая кастомизация

Разработчики могут создавать собственные модули, добавлять свои команды, GUI-меню, а также настраивать каждый мини-режим через внешние конфиги.

🎮 Почему Minecraft 1.20.1?

Стабильность, богатые возможности API и большое комьюнити. Версия 1.20.1 — идеальный фундамент для создания сложных кастомных режимов. Мой движок использует последние фичи PaperAPI, что обеспечивает высокую совместимость с плагинами и датапаками.

Уже реализованы: система арен, ивент-менеджер, шедулер скриптов, билдер режимов.
