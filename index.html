🎯 Текущая цель

Создать стабильный, лёгкий в использовании движок для мини-режимов (арены, квесты, PvP-сражения) на версии Minecraft 1.20.1. Дать возможность другим разработчикам писать скрипты без глубокого знания Java.

Кастомный движок для скриптов / мини-режимов

Custom Script Engine — мой основной проект. Это платформа для создания и управления мини-режимами на сервере Minecraft 1.20.1. Режимы описываются скриптами (JavaScript, либо простой DSL) и загружаются динамически, без перезапуска сервера.

Движок находится в активной разработке, но уже поддерживает базовый API: ивенты, управление игроками, условия победы, таймеры и кастомные команды.

🧩 Скриптовая логика

Каждый мини-режим — отдельный скрипт. Внутри можно описать спавн игроков, правила, цели и награды. Не нужно перекомпилировать ядро.

⚡ Динамическая загрузка

Скрипты перезагружаются на лету. Добавил новый режим? Просто положи файл в папку и выполни команду перезагрузки — сервер продолжает работать.

🎲 Поддержка мини-игр

Арены, кинг-оф-зе-хилл, тeam deathmatch, охотники на зверей — любые форматы. Движок предоставляет готовые хуки для игровых циклов.

🛠️ Для разработчиков

API на Java + скриптовый мост. Можно расширять функционал, добавлять свои обработчики и создавать сложные режимы без боли.

Почему 1.20.1? Стабильная версия с хорошей производительностью и широкими возможностями Paper API. Это позволяет строить надёжную основу для мини-режимов с активным онлайном.
